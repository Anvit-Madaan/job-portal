# Job Portal (MERN)

## 🚀 Features

* User authentication (Login/Signup)
* Job posting and application system
* Recruiter and user dashboards
* Search and filter jobs

## 🛠 Tech Stack

* MongoDB
* Express.js
* React.js
* Node.js

## 📦 Installation

git clone https://github.com/Anvit-Madaan/job-portal
cd job-portal
npm install
npm start
