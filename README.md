# 📁 File Share Project

A simple full-stack web application that allows users to upload files and generate shareable download links. Built using the MERN stack.

---

## 🚀 Features

- 📤 Upload files securely
- 🔗 Generate shareable download links
- ⬇️ Download files instantly
- 🗂️ Simple file management system
- ⚡ Fast and responsive UI
- 🔒 Secure backend API

---

## 🛠 Tech Stack

**Frontend:**
- React.js
- Axios
- CSS / Tailwind CSS

**Backend:**
- Node.js
- Express.js
- MongoDB
- Multer (file upload handling)

**Other Tools:**
- Git & GitHub
- REST APIs
